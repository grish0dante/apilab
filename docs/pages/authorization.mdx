This section describes how to access the protected resources of the Financial System API.

##Authorization Method
The API utilizes the standard **Bearer Token (JWT)** protocol. This means that for every request to the server, you must provide a specific token in the HTTP request header.

###How It Works
All requests must include the `Authorization` header in the following format:

`Authorization: Bearer <your_token>`

##Obtaining a Token
To gain access, follow these steps:

1.Authenticate through your organization's internal system.

2.Copy the provided JWT token.

3.Add it to your SDK configuration or HTTP client settings.

##Response Status Codes
When handling authorization, you may encounter the following errors:

Status Code	Description	Reason

| :--- | :--- | :--- |
| **401 Unauthorized** |	Unauthorized|	The token is missing, expired, or invalid.|
| **403 Forbidden** |	Forbidden|	The token is valid, but you do not have permission to access this specific resource.|

If you are using the generated **TypeScript** SDK, the authorization setup looks like this:

```typescript
import { Configuration } from "./sdk-client";

# Authorization

Цей розділ описує, як отримати доступ до захищених ресурсів Financial System API.

## Метод авторизації

API використовує стандарт **Bearer Token (JWT)**. Це означає, що для кожного запиту до сервера ви повинні надавати спеціальний токен у заголовку HTTP-запиту.

### Як це працює

Усі запити повинні містити заголовок `Authorization` у наступному форматі:

`Authorization: Bearer <ваш_токен>`

## Отримання токена

Для отримання доступу виконайте наступні кроки:
1. Авторизуйтеся через внутрішню систему вашої організації.
2. Скопіюйте наданий системою **JWT токен**.
3. Додайте його до конфігурації вашого SDK або HTTP-клієнта.

## Статус-коди відповідей

При роботі з авторизацією ви можете зустріти наступні помилки:

| Статус-код | Опис | Причина |
| :--- | :--- | :--- |
| **401 Unauthorized** | Неавторизовано | Токен відсутній, термін його дії закінчився або він невірний. |
| **403 Forbidden** | Заборонено | Токен валідний, але у вас немає прав доступу до цього конкретного ресурсу. |

## Приклад використання в SDK

Якщо ви використовуєте згенерований SDK на **TypeScript**, налаштування авторизації виглядає так:

```typescript
import { Configuration } from "./sdk-client";

const apiConfig = new Configuration({
  accessToken: "ваш_jwt_токен_тут",
  basePath: "[https://api.finance-app.local/v1](https://api.finance-app.local/v1)"
});
